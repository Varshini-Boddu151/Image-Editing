# 🎨 Image Editor App

A sleek and interactive **Image Editing Web Application** built using **Streamlit** and **OpenCV**.
Easily upload an image, apply powerful filters in real-time, and download your edited result — all in one place.

---

## ✨ Key Features

* 📤 Upload images (JPG, PNG, JPEG)
* 🎛️ Apply multiple filters:

  * Blur
  * Sharpness
  * Brightness
  * Contrast
  * Grayscale
  * Edge Detection (with Threshold controls)
* 🔍 Real-time preview (Original vs Edited)
* 🔄 Reset filters instantly
* 📥 Download edited image
* 🎨 Clean and user-friendly interface

---

## 🛠️ Tech Stack

* **Python**
* **Streamlit**
* **OpenCV**
* **NumPy**
* **Pillow**

---

## 🚀 Getting Started

### 🔧 Installation

```bash
pip install -r requirements.txt
```

### ▶️ Run the App

```bash
streamlit run app.py
```
